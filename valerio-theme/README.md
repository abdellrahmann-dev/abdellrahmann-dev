# VALERIO — WordPress theme

قالب موقع تعريفي للبدل، عربي وإنجليزي، بهوية أسود وذهبي وعارض بدلة ثلاثي الأبعاد. هذه نسخة تصميم أولى بصور تجريبية وعلامة مؤقتة لحين إضافة لوجو العميل ومواد البراند.

[تنزيل ملف القالب ZIP](./valerio-theme.zip?raw=true)

## التركيب

1. نزّل `valerio-theme.zip` واتركه مضغوطًا.
2. افتح لوحة WordPress: المظهر ← قوالب ← أضف قالبًا جديدًا ← رفع قالب.
3. ارفع الملف ثم ثبّت وفعّل **Valerio Atelier**.
4. من المظهر ← تخصيص، عدّل الهوية واللوجو والألوان وبيانات التواصل.
5. أضف صور البدل من **Valerio · Looks / البدل**. الطلبات تظهر في **Valerio · Appointments / المواعيد**.

يتطلب WordPress 6.5 أو أحدث وPHP 8.1 أو أحدث. لا يحتاج Elementor أو WooCommerce أو Node على الاستضافة. تم اختباره محليًا؛ لم يتم نشره على Hostinger أو اختبار إرسال البريد الخارجي.
